AWS requires an OSI-approved license and says recipients must not be dominated
by a single vendor or VC-funded entity. AWS also expects active maintenance and
developer-community engagement, and tends to favor projects that complement
AWS or matter to AWS customers.

## Draft project description

PermitMesh is an independent Apache-2.0 authorization profile and conformance
suite for AI agents changing software. It separates identity, permission,
enforcement, and audit so runtimes can make narrow, fail-closed decisions and
retain reviewable receipts.
